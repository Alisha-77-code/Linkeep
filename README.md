# LINKEEP (링킵) - 초등학교 수업 사이트 통합 관리 웹앱 (Google Sheets 연동)

초등학교 수업에서 학생들이 자주 사용하는 다양한 교육용 웹사이트를 한곳에서 쉽게 찾아 접속할 수 있도록 지원하는 **수업 사이트 통합 관리 웹앱**입니다.

데이터는 선생님의 **Google 스프레드시트**와 자동으로 양방향 연동되며, **Vercel**을 통해 무료로 배포할 수 있습니다.

---

## 🌟 주요 기능

### 1. 학생 화면
- **7개 카테고리 탭**: `전체`, `오늘의 수업`, `국어`, `수학`, `사회`, `과학`, `기타`
- **실시간 검색**: 사이트 이름 기준 실시간 필터링
- **5 × 5 반응형 그리드**: 데스크톱 5열(한 화면 최대 25개), 태블릿 4열, **모바일 3열**
- **정사각형 카드**: `object-fit: cover` 1:1 이미지 꽉 채움 & 자동 이모지 지원
- **최신 등록 사이트 최상단 정렬**: 새로 등록된 수업 사이트가 항상 맨 앞에 위치
- **페이지네이션**: 25개 초과 시 `< 이전 | 1 | 2 | 3 | 다음 >` 지원
- **잠금/숨김 제어**:
  - 잠금(`locked`): 🔒 아이콘 표시 및 접속 차단 안내
  - 숨김(`hidden`): 학생 화면에서 완전히 제외

### 2. 관리자 화면
- **4자리 PIN 인증**: 기본 비밀번호 `6165` (가상 키패드 & 키보드 지원)
- **수업 사이트 등록/수정**:
  - 사이트명, URL, 카테고리, 공개 상태
  - 대표 이미지 업로드: 파일 선택, 드래그 앤 드롭, **`Ctrl + V` 클립보드 이미지 즉시 붙여넣기**
  - 자동 이모지 추정 및 이모지 프리셋
  - 교사용 비공개 메모 기능
- **일괄 관리 & 페이지네이션**:
  - 페이지당 10개 표시
  - **현재 페이지 기준** 모두 선택 / 해제
  - 단일 삭제 및 선택 일괄 삭제 (확인 모달 포함)
- **구글 시트 연동**: 관리자 화면에서 등록/수정/삭제 시 구글 시트에 즉시 반영되며, 반대로 구글 시트에서 직접 엑셀처럼 수정한 내용도 웹앱에 동기화됩니다.

## 📋 Google 스프레드시트 연동 방법 (3분 완성)

1. [Google Drive](https://drive.google.com)에서 **새 Google 스프레드시트**를 만듭니다.
2. 상단 메뉴에서 **[확장 프로그램] -> [Apps Script]**를 클릭합니다.
3. 열린 편집기 창에 기존 코드를 지우고, 프로젝트의 **`google_apps_script.js`** 파일 내용을 그대로 복사하여 붙여넣습니다.
4. 우측 상단 **[배포] -> [새 배포]**를 클릭합니다:
   - 유형: **웹 앱** (톱니바퀴 아이콘)
   - 설명: `LINKEEP API`
   - 다음 사용자 권한으로 실행: **나 (내 계정)**
   - 액세스 권한이 있는 사용자: **모든 사용자 (Anyone)**  *(중요)*
5. **[배포]**를 누르고 [액세스 승인] 절차를 완료합니다.
6. 생성된 **웹 앱 URL (https://script.google.com/macros/s/.../exec)**을 복사합니다.
7. 프로젝트 루트의 `.env` 파일에 등록합니다:
```env
VITE_GOOGLE_SHEET_API_URL=https://script.google.com/macros/s/AKfycbx.../exec
```

## 🌐 Vercel 배포 방법

1. GitHub 저장소에 코드를 Push합니다.
2. [Vercel](https://vercel.com)에서 해당 저장소를 Import합니다.
3. **Environment Variables**에 다음 환경 변수를 추가합니다:
   - **`VITE_GOOGLE_SHEET_API_URL`**: 6단계에서 복사한 구글 웹 앱 URL
4. **Deploy** 버튼을 누르면 배포 완료! 학생들에게 생성된 웹사이트 주소를 공유하면 됩니다.
